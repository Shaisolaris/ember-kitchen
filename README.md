# Ember Kitchen

Restaurant site with menu, ordering flow, and table booking.

**[Live Demo](https://shaisolaris.github.io/ember-kitchen/)**

## Features

- Menu with categories and dish detail
- Ordering flow with floating cart bar
- Table booking modal
- Warm hospitality design

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js · React · Tailwind CSS
